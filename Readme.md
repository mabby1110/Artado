# Artado 🎨

Plataforma social innovadora diseñada para conectar artistas independientes y casas productoras, facilitando la contratación y colaboración en el sector creativo.

## 📝 Descripción
Artado es un proyecto desarrollado como parte de la materia de Administración de Proyectos de Software. La plataforma actúa como un puente entre el talento creativo y las oportunidades laborales, permitiendo a artistas independientes y casas productoras encontrar y colaborar en proyectos de manera eficiente.

## 💻 Tecnologías
- React
- Firebase
- MongoDB
- Webpack
- Node.js

## 🔧 Requisitos Previos
- Node.js
- MongoDB
- npm (gestor de paquetes de Node.js)
- Navegador web moderno

## ⚙️ Instalación

### 1. Clonar el repositorio
```bash
git clone https://github.com/tu-usuario/artado.git
cd artado
```

### 2. Instalar dependencias
```bash
npm install
```

## 🚀 Ejecución

### Iniciar servidor de desarrollo
```bash
npm run dev
```

### Iniciar servidor de producción
```bash
npm run start
```

### Compilar con Webpack
```bash
npm run webpack
```

### Iniciar base de datos local
```bash
mongod
```

## 🌐 Entornos

### Desarrollo
- Utiliza `npm run dev` para iniciar el servidor con hot-reload
- Ideal para desarrollo local y pruebas

### Producción
- Utiliza `npm run start` para iniciar el servidor optimizado
- Configurado para un entorno de producción
